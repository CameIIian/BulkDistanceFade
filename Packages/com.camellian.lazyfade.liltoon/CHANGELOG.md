# Changelog

## 0.2.0 — 2026-09-29

- lazyFadeへ改名。パッケージID・コンポーネント名・表示名・配布名を整理。
- .meta GUIDと保存フィールドを維持し、旧コンポーネント型にMovedFromを指定。
- lilToon／NonToonを個別のunitypackage・VPM ZIPとして配布。
- VPM一覧生成、ソースと配布アーカイブの安全チェック、導入・技術資料を追加。

## 0.1.0 - 2026-09-09

- Assets/lazyFadeへ導入するUnitypackage版とリリース説明を追加。依存パッケージとテストコードは同梱しない。

- 基本設定の先頭に組み込みプリセットのプルダウンを追加。選択時に6項目の値を即時上書きし、チェック状態とオプションは保持。
- `Editor/LazyFadeLilToonPresets.cs`に、名前と6項目を編集できる`warm`・`cold`・`none`の3件を定義。

- 除外マテリアルを標準配列リストとして直接表示し、外側の折りたたみと内側の「除外リスト」の二重構造を解消。

- 「2. 基本設定」に距離フェード4項目とリム2項目を常時表示するよう変更。
- 除外リストの標準配列GUIと外側のFoldoutHeaderGroupが入れ子になるエラーを修正。
- 集計は任意の確認操作であり、未更新でもNDMFビルド時に最新設定から適用されることをInspectorとガイドに明記。

- Inspectorを基本設定から集計まで上から順に操作する構成に変更。除外マテリアル・高度な設定は折りたたみに整理。
- 各項目の「適用」ラベルを削除してチェックボックスだけに変更。説明はツールチップに表示し、設定値と適用状態を維持。

- フェード色とリム色の初期RGBをColor32経由で正規化し、0～255の値をHDR値として扱ってしまう問題を修正。
- 既存設定の色だけを修正できる「初期色」ボタンを追加。Undo／Redoに対応し、任意のHDR設定は自動変更しない。

- 「裏面を陰にする」と「モード」の適用チェックを初期OFFへ変更。値の入力はチェックボックスと「頂点／座標」のプルダウンを使用し、保存済みの未知Mode値は保持。

- コンポーネント追加メニューを`lazyFade/lazyFade lilToon`へ変更し、Inspector・NDMF・Package Managerの表示名を`lazyFade`に統一。

- Inspectorへマテリアル除外リストを追加。共有スロットをまとめて除外し、対象・除外件数を表示。
- NDMFに登録済みの置換元情報を使い、先行処理によるMaterial置換後も除外を追跡。
- 除外・非破壊性・NDMF連携・シリアライズ互換性・Undo／Redoの回帰テストを追加。
- 動作を維持したまま色の有限値検証を共通化し、不要なusingとモード表示の中間配列変換を削除。
- READMEとGitHub Pages原稿を現在のプリセット定義・「再集計」の表示に同期し、公開前レビューを更新。

### 初期実装

- アバタールート専用の距離フェード設定コンポーネントを追加。
- HDR Color、Vector4要素別上書き、Mode、Rim設定に対応。
- NDMFによる非破壊Material複製、共有保持、出力からの設定除去を実装。
- 専用Inspector、読み取り専用集計、配置・入力検証、NDMF診断を追加。
- Edit Modeの回帰テストを追加。
