## 使い方・設定

「1. 処理の有効化」→「2. 基本設定」→「3. 集計・確認」の順に操作します。**初期状態では3項目の適用チェックがすべてOFFです。** 書き込みたい項目の左端をONにしてください。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 処理を有効化 | ON | コンポーネント全体の処理を切り替えます |
| 近距離境界 | 0.01 / 適用OFF | 減光が強くなる側の境界を指定します |
| 遠距離境界 | 0.1 / 適用OFF | 減光しなくなる側の境界を指定します |
| 強度 | 0 / 適用OFF | 0～1。強度0を適用すると減光を無効にします |
| 除外マテリアル | 空リスト | 指定したMaterialの全スロットを本コンポーネントの処理から除外します |
| 未対応NonToonでビルドを停止 | OFF | 高度な設定内。OFFでは未対応のNonToonを警告してスキップ、ONではビルドエラーにします |
| 再集計 | ボタン | 編集時点の対象・除外件数と未対応理由を確認します。Materialを変更しません |

距離は **0 ≦ 近距離 < 遠距離 ≦ 1**、強度は0～1の有限値を使用してください。一方の距離だけ上書きする場合も、元Materialから残す値と合成した最終値を検証します。無言の並べ替えやClampはしません。適用OFFと、強度0の適用は異なります。

近距離側ではRGBを黒へ減光します。距離の計算にはNonToonの`headDepth`を使います。色・リム・裏面・モードの編集は提供しません。lilToonと同じ`_DistanceFade`という宣言があっても、NonToonの強度は独立したPropertyへ書き込み、距離Vectorのz/wは保持します。

除外リストは見出しを1回開く標準配列UIです。未設定・重複は無視します。NDMFに置換元が登録されているMaterialは、先行ツールの置換後も除外を追跡します。同名という理由だけでは除外しません。lilToon用の除外リストとは独立しています。

集計は対象Renderer数、一意Material数、遭遇した除外Material数／Slot数を表示します。登録した除外要素数とは異なります。全項目OFFや処理無効時は0件です。**再集計しなくても、NDMFビルド時は最新の設定で実行します。** 他ツールがビルド中に構成を変えた場合は編集時の件数と異なります。

## プリセットの編集

基本設定の先頭でプリセットを選択すると、3項目の保存値を即時に上書きします。適用チェック、処理全体、除外、高度な設定は保持します。選択名は保存せず、実値を保存します。手動変更で個別指定表示に戻り、Inspectorを開いたときに自動適用しません。

定義箇所は[Editor/NonToonPresets.cs](../Packages/com.camellian.lazyfade.nontoon/Editor/NonToonPresets.cs)の`BuiltIn`です。`new NonToonPreset(名前, 近距離, 遠距離, 強度)`の3件を編集してください。現在は仮名・同じ値（0.01、0.1、0）です。名称・値を検証してから3項目をまとめて更新します。選択だけで元Materialの見た目を変更する機能ではありません。

## 対応範囲と注意事項

- NonToon 0.1.3の公式`NonToon.scshader`と`NonToonFur.scshader`から生成したShaderを、アセットGUID・導入版・モジュール属性・Property型で確認します。Shader名だけの判定ではありません。
- Distance FadeモジュールをShader側に組み込んでください。本ツールはモジュールの自動追加、Shader再生成、キーワード同期、元Importerの更新を行いません。
- ShaderCoreの公開`SCModule.FromFile` APIから最終Property名を解決します。属性が定数化された構成や、出自を追跡できない独自生成Shaderは対象外です。
- MeshRenderer／SkinnedMeshRendererを非アクティブ・無効も含めて走査し、同じMaterialの複製を共有します。元Materialは変更せず、ビルド出力へだけ設定します。ParticleSystemRenderer、アニメーションだけが参照するMaterialは対象外です。
- AnimationClip・MaterialPropertyBlock・描画モードは変更しません。アニメーションで値が上書きされる場合があります。
- コンポーネントの配置・重複は無効状態でも検証します。NonToon用を子階層へ追加したり、同一アバターへ複数置いたりしないでください。lilToon用との併設は可能です。
- 実アバターでのMA／TTT／AAO混在、VR・鏡・カメラでの見た目、実アップロード、Androidは手動検証が残っています。

## トラブルシューティング

| 症状・コード | 対処 |
| --- | --- |
| 対象0件／反映しない | 処理有効、各行の適用チェック、強度、除外リスト、対応版・公式Shader・モジュールの組み込みを確認します |
| NT001 | VRC Avatar Descriptorと同じGameObjectへ配置します |
| NT002 | 無効状態も含め、NonToon用を1個にします |
| NT003 | ON入力と保持する距離・強度を確認し、範囲と近距離 < 遠距離を満たす値へ修正します |
| NT004 | 表示された導入版・生成元・モジュール・Property・定数化の条件を確認します。停止をOFFにすると対象をスキップします |
| Inspectorを変えても見た目が変わらない | 適用はNDMFビルド時です。集計はプレビューではありません |
