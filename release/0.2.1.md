# lazyFade NonToon 0.2.1

NonToon版のバージョン制限を緩和しました。lilToon版の最新版は0.2.0です。

- VPMの依存指定と実行時の版チェックを、NonToon 0.1.3以上・ShaderCore 0.1.11以上の正式版へ変更しました。上限はありません。
- 公式Shaderの生成元、Distance Fadeモジュール、Property型の検査は引き続き行います。
- Inspectorと導入ガイドの対応バージョン表示を更新しました。

## 導入

VPMではlazyFade - NonToonを0.2.1へ更新してください。手動導入には`lazyFade-NonToon-0.2.1.unitypackage`を使用します。`lazyFade-NonToon-0.2.1.zip`はVPM用です。

Unity 2022.3、SDK Avatars 3.10.3以上・4未満、NDMF 1.13.1以上・2未満が必要です。依存パッケージは同梱しません。

## 検証

Unity 2022.3.22f1、SDK 3.10.5、NDMF 1.14.8、lilToon 2.3.4、ShaderCore 0.1.11、NonToon 0.1.3でEdit Modeテスト107件合格（失敗・スキップ0件）。最低版・新版・旧版・不正な版表記などのバージョン判定17ケースを含みます。新しいNonToon／ShaderCore実体での互換性は未検証です。
