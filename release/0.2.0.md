# lazyFade 0.2.0

プロジェクト名をlazyFadeへ変更しました。lilToon版とNonToon版を個別配布します。

## ダウンロード

- `lazyFade-lilToon-0.2.0.unitypackage`：lilToon用
- `lazyFade-NonToon-0.2.0.unitypackage`：ShaderCore＋NonToon用
- `lazyFade-lilToon-0.2.0.zip` / `lazyFade-NonToon-0.2.0.zip`：VPM用（UnityのImport Packageでは開きません）
- `SHA256SUMS.txt`：配布アーカイブのSHA-256

## 導入

Unity 2022.3、SDK Avatars 3.10.3以上・4未満、NDMF 1.13.1以上・2未満が必要です。lilToon版はlilToon 2.3.2以上・3未満、NonToon版はShaderCore 0.1.11とNonToon 0.1.3を使用してください。依存パッケージは同梱していません。

対応するunitypackageをインポートし、VRC Avatar Descriptorと同じGameObjectにAdd Componentの「lazyFade → lazyFade lilToon / lazyFade NonToon」を追加します。NonToon版は適用チェックをONにしてください。適用はNDMFビルド時です。

## 旧版からの更新

Unityを閉じ、プロジェクトをバックアップしてから旧Assets／Packages版を外し、新版を導入します。同じ版を重複導入しないでください。GUIDと保存フィールドを維持していますが、Scene／Prefabの参照と値を確認してから保存してください。詳細はソースのdocs/migration.mdにあります。

## 検証範囲

2026-09-29、Unity 2022.3.22f1でEdit Modeテスト90件（lilToon 62件、NonToon 28件）が合格しました。旧PrefabのGUID・型識別子からの読み込みも含みます。各unitypackageは出力・再インポート・コンパイル・全ファイルの内容一致を確認済みです。ソースと配布アーカイブの機密情報パターン検査は検出0件でした。

VPM生成はローカルの隔離コピーで検証済みです。公開先へのアップロードとVCCからの実インストール確認は、公開設定後に実施してください。実アップロード・VR／鏡／Androidの見た目や、すべての他ツールとの組み合わせは未検証です。詳細はdesign/Implementation_Validation.mdを参照してください。
