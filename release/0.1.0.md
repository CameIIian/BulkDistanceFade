# lazyFade v0.1.0

VRChatアバターのlilToon距離フェードを、1つのコンポーネントから非破壊で一括設定できるUnity Editor拡張です。NDMFビルド時にMaterialを複製し、設定を書き込みます。lilToon公式の機能ではありません。

## このリリースの内容

- 距離フェードの開始距離・終了距離・色・強度と、リム色・リムライトの細さを設定できます。
- `warm`・`cold`・`none`の組み込みプリセットを用意しました。プルダウンの選択時に6項目の値を上書きし、個別のチェック状態とオプションは保持します。
- 各項目は左端のチェックで上書きの有無を指定できます。裏面設定とモードの上書きは初期OFFです。
- マテリアル単位の除外に対応しました。NDMFに登録された置換元情報があれば、先行ツールによる置換後も除外を引き継ぎます。
- 基本設定を上から順に操作でき、除外マテリアルと高度な設定は折りたためます。対象件数を確認する「再集計」も利用できます。
- 元Materialの保持、複製Materialの共有、配置・入力の検証に対応しています。
- 色の初期値を0～255表記から正しく変換し、各色を戻す「初期色」ボタンを用意しました。除外リストの折りたたみが入れ子になるGUIエラーも修正しています。

## ダウンロードと導入

配布ファイル: **`BulkDistanceFade-0.1.0.unitypackage`**  
ライセンス: **MIT**

1. 先にVRChat SDK Avatars・NDMF・lilToonを導入してください。これらは同梱していません。
2. Unityの `Assets → Import Package → Custom Package...` からUnitypackageを選び、全項目をインポートしてください。導入先は `Assets/BulkDistanceFade` です。
3. VRC Avatar Descriptorと同じアバタールートへ、`lazyFade → lazyFade lilToon` を1個追加してください。
4. 処理を有効にして基本設定を入力し、NDMFのビルド出力で結果を確認してください。

**Packages版との二重導入はできません。** 既に `com.camellian.lazyfade.liltoon` を導入している場合は、バックアップを取って既存パッケージを外してからインポートしてください。移行後はScene／Prefabのコンポーネント参照と保存値を確認してください。

Unitypackage版は依存パッケージを自動導入・更新しません。VPM依存情報を利用するPackages版は、リポジトリの `Packages/com.camellian.lazyfade.liltoon` から導入できます。

## 使用上の注意

- Inspectorの編集や「再集計」はSceneのMaterialを直接変更しません。適用はNDMFビルド時です。「再集計」を押さなくても最新の設定で処理されます。
- `none`は6項目を上書きするプリセットです。強度の適用チェックがONなら強度0を書き込みます。ツール全体を無効化する操作ではありません。
- 初期値と3プリセットのリム色はAlpha 0です。元Materialの距離フェード用リム設定を保持するには、対応する適用チェックをOFFにしてください。
- AnimationClip、MaterialPropertyBlock、Shaderキーワード、描画モードは変更しません。Shader設定やアニメーションによって見た目が変わる場合があります。
- Poiyomi・ShaderCore／NonToonには対応していません。

詳細な設定手順はリポジトリのREADMEとdocs、更新点はパッケージ内CHANGELOGをご確認ください。
